## Temuan audit kode (fakta repo)
- `api/src/upload.js`: `unggahVideoBanner` unggah MP4 → `secure_url` (MP4, disimpan di `media_assets.url`) + `gif` hasil `f_gif` (URL `res.cloudinary.com` MENTAH). **MP4 tidak pernah dihapus** → duplikat + bocor URL. GIF/MP4 juga LOLOS dari proxy `/img/` (hanya jalur `image/upload` yang diproxy).
- `samarkanGambar` hanya memetakan `res.cloudinary.com/.../image/upload/`; jalur `video/upload` dibiarkan mentah.
- Banner media disimpan sebagai JSON `{tipe,url,gif}` di `users.banner_media`, aplikasi memakai `media.gif` (URL cloudinary mentah).
- `api/src/index.js` route `me/banner-media` POST: gabungan dua kode jalur (gif → unggahGambar; video → unggahVideoBanner), tanpa dedup, tanpa bersih MP4.
- Upload dashboard `POST /api/admin/upload` → `unggahGambar`; `media_assets.url` = URL cloudinary mentah (ditampilkan dashboard).
- `gif` transform `f_gif` tidak didukung proxy `/img/` (`imageVariant` hanya webp/avif/original).
- Flutter `ApiClient.post` timeout tetap 20 dtk, tanpa callback progres; setiap `_unggahBanner`/`_gantiFoto`/lampiran cuma spinner berputar.
- `StikerStore` sudah AES-256 tersimpan di media privat app — **sudah aman**; belum ada `/xycloudstorage/` layout galeri ala WA.
- Push icon: `push.js` memakai `ic_stat_onesignal_default` (bell OneSignal); `push_service.dart` tanpa konfigurasi ikon kustom.
- `app/android/` TIDAK di-commit (digenerate CI via `flutter create --platforms=android --org id.xycloud --project-name xycloud_order` → applicationId `id.xycloud.xycloud_order`). Tool injection ada di `tools/`.
- `schema.sql` + `migrations/` dijaga test `skema_kode.test.mjs`: kolom yang ditulis Worker WAJIB ada di schema+migrasi; penomoran migrasi harus rapat (migrasi berikutnya = 0013).
