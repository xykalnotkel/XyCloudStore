# Batch P — Editor HUD landscape & preset komunitas

Tanggal: 2026-09-16

## Yang ditambahkan

- Editor HUD 16:9 yang memaksa layar landscape selama penyuntingan.
- Tambah, pilih, geser, ganti mapping, ganti label, duplikat, hapus, serta kosongkan tombol.
- Ukuran lebar/tinggi, transparansi, dan perilaku tombol dapat diatur:
  - **Tahan**: key-down saat jari menyentuh dan key-up saat dilepas.
  - **Ketuk**: satu ketukan pendek.
  - **Toggle**: ketuk untuk menahan, ketuk lagi untuk melepas.
- Maksimal 48 tombol per preset dan posisi disimpan relatif terhadap layar.
- Tiga templat lokal: FPS Kompetitif, MOBA & RPG, dan Desktop Ringkas.
- Penyimpanan lokal offline lewat `SharedPreferences`.
- MethodChannel baru `setHudPreset` untuk menyinkronkan preset aktif ke overlay native.
- Overlay native membaca JSON, merender tombol bebas di atas video, mendukung multitouch/hold, dan melepas semua key saat layar pause/ditutup agar tidak ada input tersangkut.
- Tombol `HUD` pada bilah streaming untuk menampilkan/menyembunyikan preset bebas; ABC/F/NUM tetap tersedia.
- Galeri preset akun/komunitas:
  - publik atau privat;
  - urut populer/terbaru;
  - suka/batal suka;
  - impor & gunakan;
  - statistik jumlah suka dan penggunaan;
  - perbarui terbitan tertaut dan hapus terbitan.
- Semua proses simpan, impor, dan publikasi menampilkan tahap, progress bar, persen, durasi berjalan, serta pesan sukses/galat.

## Backend

Migrasi `0014_hud_preset_komunitas.sql` menambah:

- `hud_preset`
- `hud_preset_suka`

Endpoint terautentikasi:

- `GET /api/hud/presets?urut=populer|baru`
- `GET /api/me/hud-presets`
- `POST /api/hud/presets`
- `PATCH /api/hud/presets/:id`
- `DELETE /api/hud/presets/:id`
- `POST /api/hud/presets/:id/pakai`
- `POST /api/hud/presets/:id/suka`

Payload server dinormalisasi dan dibatasi: 1–48 tombol, keycode 1–300, label maksimal 8 karakter, koordinat 0–1, ukuran aman, opacity aman, serta mode tekan whitelist. Nama/deskripsi/game melewati moderasi teks.
