Pertanyaan yang sering masuk

Bagaimana cara mengisi saldo?

Pilih nominal di aplikasi, lakukan pembayaran sesuai instruksi, lalu saldo bertambah setelah pembayaran terverifikasi. Untuk transfer manual, cukup unggah bukti dan admin memeriksa dalam hitungan menit.

Apakah bisa main game berat?

Bisa. Paket dengan RTX 3060 ke atas mampu menjalankan game modern di 1080p 60fps. Untuk pengalaman terbaik, pakai koneksi minimal 15 Mbps dan gamepad Bluetooth.

Akun digital yang dibeli bergaransi?

Ya. Masa garansi tertulis pada setiap produk. Kalau bermasalah dalam masa itu, akun diganti tanpa biaya tambahan lewat menu Chat Admin.

Apakah datanya aman?

Password disimpan dalam bentuk hash bergaram, seluruh koneksi memakai HTTPS, dan token login disimpan di penyimpanan terenkripsi perangkat.

Kenapa aplikasinya tidak ada di Play Store?

Saat ini aplikasi dibagikan langsung lewat situs ini. Berkasnya ditandatangani dengan kunci rilis resmi kami, sehingga pembaruan berikutnya bisa dipasang menimpa tanpa masalah.
